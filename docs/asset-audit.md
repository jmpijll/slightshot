# Cross-platform asset audit

First audited after merging PRs #4, #5 and #6, at main revision `2c6eacca3fe4fbbd8d9be379577d3ef247c8d668`. Re-checked at `9bd9a83` (release 1.6.0).

The current Mac appearance is the design reference. The original audit found that the toolbar icon set was the main portability problem: Mac asked the OS for SF Symbols, while Windows drew its own approximations. [PR #9](https://github.com/jmpijll/slightshot/pull/9) replaced both with one original vector catalogue without changing toolbar layout or interaction. The app now draws no SF Symbol in the capture overlay, toolbar, recording HUD, menu bar or permission status. The four macOS Settings tab labels are the only remaining system symbols; they are Mac-only native UI.

| --- | --- | --- | --- |

| Settings tab labels | SF Symbols (`gearshape`, `command`, `square.and.arrow.down`, `viewfinder`) | WPF text tabs | Mac-only system UI, permitted on Apple platforms. Not shipped to Windows. |

| Annotation text | macOS system semibold | Segoe UI semibold | Affects saved-image text metrics as well as UI appearance. A shared annotation font would need export/layout review. |
| Cursors, file/print/permission dialogs, notifications | Native OS APIs | Native OS APIs | Keep native behavior and accessibility. These are not app-owned assets. |

## Shared icon catalogue

`Resources/UI/icons.json` holds 20 original glyphs on an 18-point grid with a 1.5-point stroke. `python3 Scripts/generate_ui_icons.py` compiles it to the Swift and C# sources; `--check` fails when either generated file is out of date, and CI runs that check. Edit the JSON and regenerate rather than editing the generated files. Draw new glyphs as original vectors; do not export or trace Apple symbols.

Keep 30-point buttons, 6-point button corners, 9-point panel corners, 4-point panel padding, 2-point button spacing, current hover/selected states and the red recording accent. A visual icon change needs before/after Mac toolbar captures and native Windows fixtures, as in the [shared icon review](review/icons/README.md).

## Platform restrictions

Apple's [Xcode and Apple SDKs Agreement](https://www.apple.com/legal/sla/docs/xcode.pdf), section 2.10, restricts Apple-owned system-provided images to applications for the corresponding Apple-branded platforms. For that reason the Windows app ships no SF Symbols, and shared artwork stays original.

The project logo is drawn from project-owned points in `Scripts/make_icon.swift`; it is not an SF Symbol.
